01 · The Big Idea

How do we describe motion?

To describe motion, we need to know how far something moves, how long it takes and how its motion changes.

📏

Distance

The total length of the path travelled by an object. Distance is a scalar quantity.

🏎️

Speed

How quickly distance is covered. Speed tells us how fast an object is moving.

⏱️

Time

The duration taken for an event or for an object to travel a certain distance.

02 · Speed vs Velocity

Speed and velocity are not the same.

Speed tells us how fast something moves. Velocity tells us how fast it moves and in which direction.

➡️

Velocity

Velocity is speed in a specified direction. It is a vector quantity.

🔄

Direction matters

Two objects can have the same speed but different velocities if they move in different directions.

🎯

Displacement

Displacement is the distance travelled in a specified direction from the starting point.

Remember velocity = displacement ÷ time

03 · Acceleration

How quickly is velocity changing?

Acceleration measures how quickly velocity changes with time. An object accelerates whenever its velocity changes.

Key equation acceleration = change in velocity ÷ time taken

a = (v − u) ÷ t

04 · Motion Graphs

Graphs tell the story of motion.

A graph allows us to see how an object's motion changes over time. The gradient of a graph can give us important information.

📈 Distance–Time Graph


Think: The gradient of a distance–time graph represents the speed of the object.

📊 Velocity–Time Graph


Remember: The gradient of a velocity–time graph represents acceleration. The area under a velocity–time graph represents distance travelled.

Gradient

For a velocity–time graph:

acceleration = change in velocity ÷ time

Area

For a velocity–time graph:

distance travelled = area under the graph

05 · Gravity

What happens when objects fall?

In the absence of air resistance, all objects near Earth's surface fall with the same acceleration due to gravity.

🎯 Motion — What You Should Know

  • Speed = distance ÷ time.
  • Velocity is speed in a specified direction.
  • Acceleration = change in velocity ÷ time.
  • The gradient of a distance–time graph gives speed.
  • The gradient of a velocity–time graph gives acceleration.
  • The area under a velocity–time graph gives distance travelled.
  • Objects in free fall accelerate due to gravity.
  • Without air resistance, all objects fall with the same acceleration.
